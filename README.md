Проект E-commerce

Описание:
E-commerce — электронная торговля, или электронная коммерция. 
На данном этапе работы мы подготовили всё для того, чтобы у нас появилось ядро для интернет-магазина.

Установка:
1.Клонируйте репозиторий:
git clone https://github.com/Dinar513/HomeWork14.1

2.Установите зависимости:

pip install poetry

Использование:

Откройте приложение в Pycharm и задайте необходимые аргументы в функции.

Тестирование:
1.Наш проект покрыт тестами pytest. Для их запуска выполните команду:

pytest

2.В файле реализовано тестирование фунцкий, размещенных в папке test.
3.Для визуализации результатов тестировоания необходимо выполнить следующее.
4.В терминале Pycharm набрать команду pytest --cov.
